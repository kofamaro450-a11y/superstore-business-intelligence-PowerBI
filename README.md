# Superstore Business Intelligence & Power BI Dashboard

## Project Overview

This project was completed as part of the AnalystLab Africa Data Analytics Internship Programme – Week 2 Business Analytics Case Study.

The project uses the Superstore Sales Dataset to analyse sales performance, profitability, customer segments, product categories, and regional performance using Microsoft Power BI.

## Business Objective

The objective of this project is to transform retail transaction data into meaningful business insights that can support management decision-making and improve overall business performance.

## Tools Used

- Microsoft Power BI
- Power Query
- Microsoft Excel/CSV
- GitHub

## Key Performance Indicators

- Total Sales: $2.30M
- Total Profit: $286.40K
- Total Orders: 5,009
- Average Sale: $229.86
- Profit Margin: 12.47%

## Key Business Insights

1. West is the strongest-performing region.
2. Central has the weakest regional profitability.
3. Technology is the most profitable product category.
4. Furniture generates strong sales but weak profitability.
5. Overall sales and profit increased over the period analysed.

## Business Recommendations

1. Review Furniture pricing and product costs.
2. Control excessive discounting.
3. Increase investment in high-margin Technology products.
4. Investigate Central-region profitability.
5. Replicate successful strategies from the West region.
